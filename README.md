## 🔓 Open-Source GitHub Projects

*Sorted by GitHub Stars_Count (Descending)* 🌟

- **[Twenty](https://github.com/twentyhq/twenty)** [![Stars](https://img.shields.io/github/stars/twentyhq/twenty?style=social&color=white)](https://github.com/twentyhq/twenty/stargazers)  
  **Modern open-source CRM built with TypeScript and React**, AGPL-3.0 licensed. Designed as a flexible, modern, self-hostable alternative to Salesforce with clean UI and GraphQL API. ⚡

- **[ERPNext](https://github.com/frappe/erpnext)** [![Stars](https://img.shields.io/github/stars/frappe/erpnext?style=social&color=white)](https://github.com/frappe/erpnext/stargazers)  
  **All-in-one open-source ERP with comprehensive CRM capabilities**, GPL-3.0 licensed. Full business suite covering lead management, sales pipeline, invoicing, inventory, and HR. 🏢

- **[Monica CRM](https://github.com/monicahq/monica)** [![Stars](https://img.shields.io/github/stars/monicahq/monica?style=social&color=white)](https://github.com/monicahq/monica/stargazers)  
  **Personal relationship management open-source CRM**, AGPL-3.0 licensed. Document interactions, track personal/professional contacts, and set automated follow-up reminders. 👤

- **[Krayin CRM](https://github.com/krayin/laravel-crm)** [![Stars](https://img.shields.io/github/stars/krayin/laravel-crm?style=social&color=white)](https://github.com/krayin/laravel-crm/stargazers)  
  **Handcrafted Laravel-based open-source CRM**, MIT licensed. Enterprise-grade pipeline management, modular architectural components, and lightweight deployment. 🛠️

- **[Dolibarr](https://github.com/Dolibarr/dolibarr)** [![Stars](https://img.shields.io/github/stars/Dolibarr/dolibarr?style=social&color=white)](https://github.com/Dolibarr/dolibarr/stargazers)  
  **Modular open-source ERP and CRM for SMEs**, GPL-3.0 licensed. Enable only the modules you need — customer tracking, invoicing, proposal generation, and stock management. 📦

- **[SuiteCRM](https://github.com/salesagility/SuiteCRM)** [![Stars](https://img.shields.io/github/stars/salesagility/SuiteCRM?style=social&color=white)](https://github.com/salesagility/SuiteCRM/stargazers)  
  **Enterprise-class open-source CRM framework**, AGPL-3.0 licensed. Successor to SugarCRM Community Edition with workflow automation, security roles, and deep module customizability. 🏛️

- **[Frappe CRM](https://github.com/frappe/crm)** [![Stars](https://img.shields.io/github/stars/frappe/crm?style=social&color=white)](https://github.com/frappe/crm/stargazers)  
  **Fully-featured, modern CRM built on Frappe Framework**, MIT licensed. Features a Python backend and Vue.js frontend, seamlessly integrating with the ERPNext ecosystem. 🚀

- **[EspoCRM](https://github.com/espocrm/espocrm)** [![Stars](https://img.shields.io/github/stars/espocrm/espocrm?style=social&color=white)](https://github.com/espocrm/espocrm/stargazers)  
  **Open-source CRM with SPA frontend and REST API**, AGPL-3.0 licensed. Productivity-focused UI, customizable admin controls, audit logs, and rich role permissions. 🎯

- **[Django-CRM](https://github.com/MicroPyramid/Django-CRM)** [![Stars](https://img.shields.io/github/stars/MicroPyramid/Django-CRM?style=social&color=white)](https://github.com/MicroPyramid/Django-CRM/stargazers)  
  **Python and Django open-source CRM for startups**, MIT licensed. Analytical CRM featuring sales pipeline tracking, task management, and built-in email marketing tools. 🐍

- **[DaybydayCRM](https://github.com/Bottelet/DaybydayCRM)** [![Stars](https://img.shields.io/github/stars/Bottelet/DaybydayCRM?style=social&color=white)](https://github.com/Bottelet/DaybydayCRM/stargazers)  
  **Lightweight open-source CRM for daily workflows**, MIT licensed. Laravel/PHP-based starter CRM to manage daily tasks, client leads, and project assignments. 📅

- **[Corteza](https://github.com/cortezaproject/corteza)** [![Stars](https://img.shields.io/github/stars/cortezaproject/corteza?style=social&color=white)](https://github.com/cortezaproject/corteza/stargazers)  
  **Open-source low-code platform and enterprise CRM suite**, Apache-2.0 licensed. Automated workflow builder, record management, and customizable web dashboards. 🌐

- **[YetiForce CRM](https://github.com/YetiForceCompany/YetiForceCRM)** [![Stars](https://img.shields.io/github/stars/YetiForceCompany/YetiForceCRM?style=social&color=white)](https://github.com/YetiForceCompany/YetiForceCRM/stargazers)  
  **Feature-rich open-source CRM with 100+ built-in modules**, open-source licensed. Flexible business process customization covering complex operational workflows out-of-the-box. ⚙️

- **[OroCRM](https://github.com/oroinc/crm-application)** [![Stars](https://img.shields.io/github/stars/oroinc/crm-application?style=social&color=white)](https://github.com/oroinc/crm-application/stargazers)  
  **Flexible multi-channel CRM built on Symfony framework**, OSL-3.0 licensed. Optimized for sales, marketing, and B2B eCommerce integration. 🏗️

- **[CiviCRM](https://github.com/civicrm/civicrm-core)** [![Stars](https://img.shields.io/github/stars/civicrm/civicrm-core?style=social&color=white)](https://github.com/civicrm/civicrm-core/stargazers)  
  **Open-source constituent relationship management CRM**, AGPL-3.0 licensed. Designed for non-profits, civic associations, and advocacy organizations. 🏛️

1. 🍴 **Fork** the repository.
2. 📝 **Add/edit** entries in `README.md` maintaining table/list structure and formatting.
3. 🔗 Include project title, official website/GitHub link, exact Stars_Count, license, and brief description.
4. 🚀 Submit a **Pull Request** with a descriptive summary of your changes.
